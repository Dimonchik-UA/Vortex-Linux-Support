OVLS

Linux Support for Official Vortex. OVLS adds SteamOS/Linux integration that helps run the official Windows version of Vortex Mod Manager through Proton.

Download latest release View source on GitHub

What OVLS provides

  • Launches the official Vortex application through the Proton tool selected for its Steam prefix.
  • Integrates nxm:// links, so Nexus Mods download links can open in Vortex.
  • Installs a separate Vortex Extension for Linux-related staging-folder support.
  • Includes OVLS Manager for installation, updates, verification, prefix selection and removal.

OVLS is a separate compatibility layer. It does not modify the official Vortex application files or replace Vortex. It installs and manages its own Extension and desktop integration.

Compatibility

Testing has been performed on SteamOS 3.x in Desktop Mode (KDE Plasma). DW-Proton Latest and Proton-GE Latest worked normally in the tests and are recommended, but are not required. Proton 11.0, Hotfix and Experimental showed window-display and cursor-position issues in testing.

SteamOS Game Mode has not been tested. OVLS does not guarantee compatibility with every game or every future version of Vortex, SteamOS or Proton. Review the limitations before installing.

Installation

  1. Download OVLS-Installer.tar.gz and SHA256SUMS from the latest GitHub release.
  2. Verify the archive using sha256sum -c SHA256SUMS.
  3. Extract the archive and open the OVLS Installer folder.
  4. Run bash install.sh and choose Install / Update.

See the full installation instructions for requirements and details.
